■ 주소 (폰 크롬에서 열기)
   https://0702080.github.io/nametag.html

   도구 모음 첫 화면:
   https://0702080.github.io/


■ 폰에 앱처럼 설치 (1회만)
   1) 크롬으로 위 주소 열기
   2) 우측 상단 ⋮ 메뉴
   3) "홈 화면에 추가"
   → 홈 화면 아이콘으로 전체화면 실행


■ 사용법 (초간단)
   · 왼쪽 위 [✏️ 편집] → 이름 / 전화번호 → [크게 표시하기]
   · 전화번호는 숫자만 입력 (01091982020)
     → 하이픈 자동 (010-9198-2020)
   · 다음 성도로 바꿀 때: [편집] → 이름만 고치고 표시
   · [✕ 지우기] 화면 비우기
   · [◐ 배경]  흰 배경 ↔ 검은 배경
   · [⛶ 전체화면] 주소창까지 완전히 숨김


■ 화면 표시 방식
   · 세로로 들면 → 전화번호가 3줄로 나뉘어 아주 크게
        김재식
        010-
        9198-
        2020
   · 가로로 들면 → 전화번호 한 줄로 크게
   · 글자 크기는 화면에 꽉 차게 자동 조절


■ 촬영 팁 (성도를 뒤에 세우고 촬영)
   · 표시 중에는 화면이 꺼지지 않음 (자동 잠금 방지)
   · 코너 버튼은 3초 뒤 흐려져 사진에 거의 안 나옴
   · 배경 선택:
       실내 조명 밝음 → 검은 배경 + 흰 글씨 (눈부심 적음)
       어두운 곳     → 흰 배경 + 검은 글씨
   · 폰 밝기는 중간 정도로 (너무 밝으면 사진에서 글자가 번짐)
   · 최근 입력한 이름 8개가 버튼으로 남아 재선택 가능


■ 개인정보
   · 페이지는 공개 주소지만 이름·전화번호는 서버에 저장 안 됨
   · 내 폰 안에만 저장 → 성도 정보가 인터넷에 올라가지 않음


■ 인터넷 없이도 동작
   한 번 연 뒤에는 오프라인에서도 사용 가능
